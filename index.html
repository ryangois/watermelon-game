Como jogar

  1. Mova a fruta para escolher onde ela vai cair.
  2. Toque ou clique no pote para soltar. No teclado, use as setas para mirar e espaço para soltar.
  3. Junte duas frutas iguais para formar uma maior.

Não deixe as frutas acumularem acima da linha.
